# 变更计划：a11y 系统改造

## 目标

全站从「基本只能鼠标操作」升级为「键盘全程可操作、屏幕阅读器可理解、自动尊重系统无障碍偏好」，鼠标用户视觉与交互零变化。三个子目标：

1. **键盘可达**：全部裸 div/span 交互目标可 Tab 触达、回车/空格可触发。
2. **弹层焦点管理**：模态弹层焦点圈禁 + Esc 关闭 + 关闭后焦点还原 + `role="dialog"`。
3. **系统偏好**：`prefers-reduced-motion` 自动尊重；全局键盘焦点可见。

## 非目标

- 不改变任何视觉设计、布局、动效对鼠标用户的表现（焦点圈仅在键盘操作时出现）。
- 不替换 Element Plus 组件（开关/滑杆/radio 本身可访问，不重复造轮子）。
- 不动右键屏蔽（站点既定特色功能，保留）。
- 不做全量 WCAG 对比度自动审计（玻璃拟态背景随壁纸变化，只能定性核验；记入 STATUS 风险）。
- 不做多语言（i18n 是独立候选，不混入）。

### B. 弹层（4 个模态 + 搜索浮层）

- MoreSet、Friends、音乐列表、SearchOverlay：无 `role="dialog"`/`aria-modal`、无焦点圈禁（Tab 漏到背景）、仅 SearchOverlay/音乐列表支持 Esc、关闭后焦点不还原。
- SearchOverlay 结果行无 listbox/option 语义，读屏不可感知选中态。

### C. 全局

- 全站零 `:focus-visible` 样式，键盘焦点不可见。
- 「降低动态效果」仅手动开关，不响应系统 `prefers-reduced-motion`。
- 装饰元素未声明：壁纸 `alt="cover"`、樱花 canvas 无 aria-hidden；Loading 无 `role="status"`。

## 复用的现有方案

- matchMedia 单例监听模式：照抄 `useDarkMode.ts`（模块级 ref + 首次调用挂 listener + jsdom 缺 matchMedia 守卫）。
- 焦点圈禁自写 composable `useModalA11y`（约 80 行）：**不引第三方 focus-trap 依赖**——Element Plus 内置版不对外导出，引入 focus-trap/vueuse-integrations 仅为此一处小功能，违背本仓库最小依赖取向（terser 刚被移除）；自写逻辑面窄（Tab 循环 + Esc + 焦点还原），测试可覆盖。
- hover 显形的键盘补位统一用 `@focusin/@focusout`（焦点在面板内即显形），不引入 CSS `:focus-within !important` 与 v-show 内联 display 的对抗。

## 风险

- `<a>` 化的卡片会命中全局 `a:hover`（变蓝+下划线），需 scoped 覆盖。
- `<button>` 化需逐一重置 UA 样式（background/border/font/cursor），漏一处就有视觉回归——走查时逐个比对。
- jsdom 无 matchMedia：useReducedMotion 需守卫（照抄 useDarkMode）。
- 两个弹层同时打开属边缘态（现设计已互斥，Ctrl+K+音乐列表叠开仅理论可能），焦点圈禁按「各自面板循环」处理，记为已知限制。

## 实施步骤

1. 批次 A（机械替换）：上表 A 全部 + 装饰元素（Background alt、Sakura aria-hidden、Loading role=status）。
2. 批次 B（弹层焦点）：`useModalA11y` composable + 四弹层接入（role/aria-modal/Esc/圈禁/还原）+ SearchOverlay combobox 语义 + composable 单测。
3. 批次 C（全局）：style.scss `:focus-visible` 焦点圈 + `useReducedMotion`（ripple.ts 与 App.vue 改读合并值）。
4. 每批次跑四门禁；收尾 CHANGELOG/STATUS + dev 纯键盘走查。

## 验收标准

- [ ] 纯键盘（不开鼠标）可完成：开盒→开设置→改壁纸→关闭→开友链→开搜索→搜索跳转→Esc 全程。
- [ ] 四弹层打开时 Tab 不逃逸、Esc 可关、关闭后焦点回触发元素。
- [ ] 全站交互元素均有可读名称（读屏视角无「无标签按钮」）。
- [ ] 系统开启减弱动态时，首屏即无樱花/波纹/入场动画。
- [ ] 鼠标用户视觉零变化（除可点击卡片补 `cursor: pointer`）。
- [ ] 四门禁全绿；既有 51 用例不回归。
